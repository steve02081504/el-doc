计算消息的 SHA-256 摘要。

```el
export fn sha256_digest(message: Number[]): Number[]
```

**返回类型**：[`Number`](../number/number.md#api-3cc24d3ef702e8652fb4)[]

**参数**：message 输入字节数组，每个元素必须是 0 到 255 的整数。

**返回值**：32 字节摘要。

**失败与异常**：输入字节无效或消息超过 SHA-256 长度字段范围时抛出 CryptoError。

### 示例：计算空消息摘要

