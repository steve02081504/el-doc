# 泛型、类型参数与约束

| 要表达的内容 | 写法与边界 |
| --- | --- |
| 由实际参数类型特化函数 | 普通函数默认泛型；参数注解可以省略 |
| 接收一个类型 | 类型工厂的普通参数写成 `element: type` |
| 接收参与类型计算的值 | 尖括号内写 `参数名: 值`，值须满足该类型计算的静态要求 |
| 省略一个类型实参的名称 | 只有一个实参，且原声明的第一个形参是类型形参时允许 |
| 传多个类型／值实参 | 每项都具名，顺序不影响绑定后的类型身份 |
| 声明静态类型能力准入 | `@requires(predicate)`，谓词返回空文本表示接受，非空文本给出原因 |
| 静态类型未知 | 不自动退化为 `any`；`@requires` 的未知类型规则另见下文 |

## 普通函数按实际使用特化

没有类型注解的形参不表示先把参数装入 `any`。编译器按实际使用确定类型并生成具体函数实例；函数体使用的运算、复制、析构、异常与清理也必须在实例分析中确定。

下面是独立的局部语法示例，展示同一函数接收不同类型；已按语法合同静态核对，未编译或运行。

```el
fn keep(value) { return value }

let count = keep(3)
let label = keep("items")
```

静态特化与编译期求值是两件事。参数的类型已知，足以选择变体；参数的值仍可以来自运行期。联合类型在调用点已知实际成员时优先静态分派，不能确定时才按受检合同动态分派。未特化模板本身不是可直接执行的运行时函数。

推断需要递归调用图上的类型与属性收敛。有限联合可以合并，重复实例可以复用；无法确定返回类型或布局、出现无限类型增长时，应报告依赖环并要求必要的显式注解，不能悄悄选择 `any`。运行期装载新源码需要新组合时，规范要求先分析、生成并缓存相应实例；这不等于所有动态组合已在初次构建时穷尽。

## 类型工厂接收类型和值

类型工厂是返回 `type` 的普通 EL 函数。类型参数接收类型身份，值参数接收参与计算的普通值；二者都由真实声明的参数名绑定，不按库名赋予特殊含义。

下面是完整的类型声明片段；两个别名指向同一工厂、同一组参数生成的类型。示例已静态核对，未编译或运行。

```el
fn Slot(element: type, width = 8): type {
	return @assign(mode: "copy") class {
		let value: element
		let reservedWidth = width
	}
}

let Narrow: type = Slot<element: Number, width: 8>
let Same: type = Slot<width: 8, element: Number>
```

这里的 `width` 保存为元数据字段，不自动改变 `value` 的位宽；编译器不会从参数名称猜测布局策略。

工厂返回类的身份由工厂声明、模块版本、参数规范值及捕获类型身份决定。相同组合复用类型；不同工厂即使生成相同字段布局，也不成为同一类型。默认参数补齐后再比较，不因具名实参书写顺序不同而产生另一种类型。

固定字段布局所依赖的计算必须在布局确定前完成，运行期未知参数不能直接改写已经建立的布局。递归遇到尚未完成的相同参数调用应报告循环；持续生成新参数而不收敛时应报告资源预算诊断，不能静默换成其他类型。

声明级 `fn name<A, B>(...)` 泛型角色与普通 `element: type` 值参数在规范中分别处理，不能互相代换来推断完整高阶合一或证明能力。这里的工厂示例使用普通类型值参数；涉及依值证明的接口应同时核对其专门合同。

## 单一类型实参可以省名

省名只允许实参列表恰好有一项，而且原声明的第一个形参是类型形参。省名后按该形参的名称归一化；其余形参使用默认值，没有默认值的必填形参仍会造成缺参错误。

沿用上面的 `Slot` 声明，下表是局部语法对照，故意错误项不能作为程序运行。

| 写法 | 规则 |
| --- | --- |
| `Slot<Number>` | 等价于 `Slot<element: Number>`，并采用默认的 `width` |
| `Slot<element: Number, width: 6>` | 两项都具名，合法 |
| `Slot<Number, width: 6>` | 错误：多项实参不能使用单项省名 |
| `Slot<width: 6>` | 错误：仍缺少必填的 `element` |
| `Slot<element: Number, element: Text>` | 错误：同一形参重复绑定 |

值参数不能使用这一省名入口。布尔标志也须写成 `strict: t`，不能把 `Factory<strict>` 理解为“启用 strict”。省略的是实参名称，剩下的类型表达式按原声明的首类型形参解析，不读取调用处碰巧同名的值绑定。嵌套单项类型实参仍适用同一规则。

尖括号类型实参与普通调用的关键字实参是不同入口。普通调用的 `f(first, option: value)` 允许位置项在前、关键字项在后；不能因此把同样的混排规则套到多项类型实参上。

## `@requires` 检查静态类型能力

`@requires(predicate)` 用普通谓词表达编译期准入，不另设约束 DSL。谓词须是源码中可解析的单参数函数，接收调用点的静态类型值并返回 `Text`：空字符串表示满足约束，非空字符串作为原因附在定位诊断中。属性按导入声明身份绑定；关闭 prelude 时需要显式导入。

每个静态已知的实参类型分别检查；变长实参在打包前逐项检查。已知类型的谓词无法求值、超过循环或递归预算、没有返回字符串，都是编译错误。已知类型缺少必要元信息也不能被归入“未知类型”而跳过。

调用点静态类型未知时，只跳过这一项静态准入；既不因此拒绝调用，也不自动生成通用的运行期谓词检查。实际值的范围、形状或协议校验仍由相应库入口负责。因此，静态准入通过不等于验证了每个运行期值，也不证明结合律等语义定律。

谓词可使用受限的编译期类型反射查询，包括类型类别、字段、方法、子类型和工厂的类型实参。查询遵循真实类型及声明身份，不根据 `Number`、`Array` 等普通拼写推断能力；类型实参查询只读取声明为 `type` 的形参，不读取任意值参数。这些查询没有通用的运行期类型值表示，不能直接搬进普通运行期代码。
