# 重载解析

同一个名字可以对应多个函数。调用时，EL 先排除参数形状或类型不匹配的函数，再逐个实参比较剩余候选。只有一个候选胜出时调用才确定；没有候选或不能分出唯一胜者时，调用报错。

## 类型转换等级怎样影响候选

每个实参分别按下表从优到劣比较；普通调用不自动执行显式转换，每条转换路径最多包含一层用户隐式转换。

| 顺序 | 匹配方式 | 怎么理解 |
| --- | --- | --- |
| 1 | 精确类型 | 实参与形参类型相同 |
| 2 | 唯一基类视图或联合注入 | 实参可直接作为唯一基类视图，或进入接纳它的联合类型 |
| 3 | 结构接口 | 实参满足接口的完整形式合同，且该合同比另一候选更具体 |
| 4 | 用户隐式转换 | 源类型或目标类型提供合格的隐式转换 |
| 5 | 装入 `any` | 实参被放进动态类型容器 |

例如，若一个类型同时能精确匹配形参 `Number`，也能装入形参 `any`，精确匹配胜出。显式转换不参与这次调用：若只有 `operator Text()` 能让实参适配 `Text` 形参，普通调用不会暗中调用它，应由源码显式写转换。

基类转换先比子对象路径长度，只接受最短且唯一的路径。结构接口按完整合同的严格包含关系比较，不统计“谁的方法更多”。

## 多个参数如何一起决定胜者

候选 A 要胜过候选 B，必须在每个参数上都不比 B 差，并且至少一个参数更好。不会把各参数的等级加起来算总分。

| 候选 A 的参数表现 | 候选 B 的参数表现 | 结果 |
| --- | --- | --- |
| 每项都不差，至少一项更好 | 至少一项较差 | A 支配 B |
| 第一个参数更好 | 第二个参数更好 | 两者互不支配，歧义 |
| 每项都同等适用 | 每项都同等适用 | 歧义 |

因此，声明顺序、导入顺序以及“总的转换看起来更少”都不能替代逐参数比较。多个同阶基类路径也不能随便选择。没有任何适用候选时是无匹配错误；有多个最优候选时是歧义。

## `ref`、`rvalue` 和普通参数怎样比较

匹配的 `ref` 或 `rvalue` 形参比相应普通值形参更具体。同一个实参同时满足 `ref` 和 `rvalue` 时，`ref` 更具体，因为它借用槽位而不消费这个值。

| 实参 | 可匹配模式 | 结果 |
| --- | --- | --- |
| 可写左值，例如变量 `count` | 普通值、`ref` | `ref` 比相应普通值参数更具体 |
| 右值，例如字面量 `2` | 普通值、`rvalue` | `rvalue` 比相应普通值参数更具体 |
| `const` 左值 | 普通值 | 不能绑定可写 `ref`，也不匹配 `rvalue` |
| 按最后使用规则已确定并在此调用移出的左值 | 普通值、符合条件的 `rvalue`；也可能匹配 `ref` | `ref` 仍比 `rvalue` 更具体 |

下面的调用形状展示变量与字面量的差别；`select` 表示分别提供这些参数模式的重载函数族。

```el
let count = 1
select(count)  // 可写左值：ref 候选优先于普通值候选
select(2)      // 右值：rvalue 候选优先于普通值候选
```

普通函数形参模式和引用值类别的详细语义见[生命周期、借用与清理](lifetimes.md)。

## 具名参数、默认值与参数展开

位置实参写在具名实参前。位置参数先按位置绑定，再按声明名称绑定具名实参；未知名称、重复绑定或冲突绑定报错，具名实参不能绑定参数包。调用实参按源码顺序各求值一次。

省略形参或传入 `void` 时，调用会求值该参数的默认表达式；传入 `nil` 不会触发默认值。默认值从左到右初始化，可以引用已初始化的前序参数和函数定义处可见的外部绑定，不能引用后序参数。每个重载候选保留自己的定义上下文；默认表达式中的副作用、异常、异步和族属性也参与函数属性推断。

例如，下面只展示具名参数的绑定顺序，`format` 的参数名应以其实际声明为准：

```el
format(1, right: 2)
```

固定形参调用必须在编译期确定展开后的参数数量和各位置类型；真正的可变尾部可以接收运行期元素序列。参数包细节见[函数](functions.md)。

## 函数名作为值时保留什么

单独读取一个有重载的函数名，得到的是有限的可调用体集合，不会立即挑选某个函数。调用实参或明确的函数／可调用接口类型可以把集合缩成唯一候选；没有具体类型约束时，保存、传参和返回会保留整个集合。装入 `any` 也保留集合元数据，但必须先缩窄到明确的可调用合同才能调用。

重载集合不能直接参加算术、字符串拼接或条件转换。先调用它、显式转换或用类型注解确定候选，再用于这些位置。歧义诊断应列出候选来源及各自适用的原因。

运算符重载也按相同原则比较。候选可来自类内声明、词法可见的类外声明，以及操作数相关类型定义模块导出的关联类外声明；类内声明和导入顺序都没有额外优先权。
