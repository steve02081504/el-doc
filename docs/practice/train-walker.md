## 用种子安排八块踏板

将程序保存为 `terrain.el`，运行 `el run terrain.el`。每块踏板的中心坐标以米为单位，踏板间隔一米，高度在零到二十厘米之间。

```el
import { Random } from "el:random/"
import { Vec3 } from "el:game/three-dimensional.el"

fn terrain(random: Random): Vec3[] {
	let tiles: Vec3[] = @[]
	for let index in ..8 {
		tiles.push(Vec3(0, random.between(0, 20) / 100, index))
	}
	return tiles
}

let tiles = terrain(Random())
for (let tile in tiles) console.stdout.writeLine(tile.x, ", ", tile.y, ", ", tile.z)
```

观察八行坐标的最后一列从 0 递增到 7。需要复现实验时，用下方种子入口替换 `Random()`：

```el
// @external terrain: fn(Random): Vec3[]
let tiles = terrain(Random(17))
```

两个相同种子的独立生成器应给出相同的八行坐标。扩成关卡时，在每个中心生成长宽固定的碰撞盒，保持踏板顶面与采样的高度一致，起始踏板设为水平。坡度、摩擦和间距应分开随机化，保留一组独立种子专门测试。

## 先让一个环境跑完，再让一批同时跑

| 边界 | 数据 |
| --- | --- |
| 重置 | 用种子重建场景，把骨盆、关节、速度与足底接触状态复位 |
| 观测 | 骨盆高度和姿态、线速度、每个关节的位置与速度、脚是否触地、近处地形高度 |
| 动作 | 每个受控关节一个归一化目标，映射到该关节的物理角度范围 |
| 步进 | 在固定模拟时长内应用动作并更新接触，返回下一帧观测、奖励和结束原因 |
| 奖励 | 前进距离减去失衡与能耗代价，摔倒结束。记录各项原值，检查原地抖动和滑行没有高分 |

先手写一段固定动作序列作为回归输入。检查同一种子和动作序列会给出相同的结束步和距离。接神经网络时让策略输出关节动作，价值估计预测后续总奖励，保存观测、动作、对数概率、奖励和结束原因，再按固定长度的轨迹更新。摔倒终止与达到采样时间上限需要分别处理：后者仍可用末帧价值估计继续计算回报。

!!! example "核对奖励方向"
    设一帧前进 0.08 米，能耗代价 0.01，姿态代价 0.02。按表里的定义，本帧奖励为 0.05。把距离换成 -0.08，奖励变为 -0.11。

## 保存、加载和评估

- **部署策略。** 保存网络结构、权重、关节顺序、动作区间和观测归一化统计。加载后给两个实例输入同一条观测，比较每个关节的输出。
- **继续训练。** 额外保存优化器、随机数状态、环境的物理状态、正在收集的轨迹和步数。恢复后先比较一次固定步进的观测与奖励，再比较一次参数更新。
- **查看进步。** 用独立种子报告通过距离、摔倒率与单位距离能耗。对比平地、台阶与坡面，避免一个平均值掩盖某类地形完全失败。
