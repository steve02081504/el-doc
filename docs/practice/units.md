# 带单位算距离和速度

> 量了两段跑道，一段是 125 厘米，一段是 0.75 米。怎么把它们加起来，再用同一种单位报出总长？

!!! abstract "🎯 做完这页，你能"
    - 用米和厘米构造量值，把两段距离加起来
    - 用距离除以时间求速度，再换算成千米每小时
    - 判断哪些量值可以相加，哪些会触发量纲错误

    <span class="el-chip">⏱ 约 10 分钟</span> <span class="el-chip">前置：[重复的计算只写一次](../beginner/functions.md)</span>

!!! note "实现状态"
    示例按当前 `el:units/` 源码编写，尚未经过 EL 编译和运行验证。

## 先把两段距离加起来

把[完整示例 `units.el`](fixtures/units.el)保存到本地，在文件所在目录运行：

```sh
el run units.el
```

预期输出：

```text
总长 200 cm
换成米 2 m
平均速度 10 m/s
换成千米每小时 36 km/h
```

程序用 `centimetre.of(125)` 和 `metre.of(0.75)` 保存两次测量。`centimetre` 和 `metre` 都是单位（`Unit`），`.of(...)` 把数字与单位一起存成量值（`Quantity`）。米和厘米都描述长度，长度就是它们共同的**量纲**。

??? question "先猜：把 0.75 米放到加号左边，结果会用什么单位？"
    结果会用米。加法把右边换成左边的单位，再相加。两种写法得到的总长度都相同。

| 写法 | 得到什么 |
| --- | --- |
| `total.valueIn(metre)` | 数字 `2`。适合交给只收数字的接口 |
| `total.inUnit(metre)` | 仍然带单位的量值 `2 m`。可以继续参与单位运算 |
| `total.inUnit(metre).standardText()` | 用固定单位符号显示的文本 `2 m` |

!!! warning "长度加上时间会报错"
    把第二段改成 `second.of(0.75)`，相加时会抛出 `UnitError`。先看两边在测量什么。计算总长度时，两项都要是长度。

## 先组合单位，再换算速度

在另一项测量中，物体用 2 秒走完 20 米。示例中的 `metre.of(20) / second.of(2)` 同时处理数字和单位，得到 `10 m/s`。`metre / second` 和 `kilometre / hour` 描述同一种量纲，所以可以用 `speed.valueIn(kilometre / hour)` 取得 `36`。

单位也可以取整数幂。`(metre ^ 2).of(5)` 表示 5 平方米。计算面积时，把两个长度量值相乘就能得到面积量值。

!!! example "把 2 秒改成 4 秒"
    修改 `second.of(2)` 为 `second.of(4)`，保持距离为 20 米。末两行应得到 `5 m/s` 和 `18 km/h`。

??? note "可选 · 自定义单位和数值类型"
    从 `el:units/` 导入 `defineUnit`。`defineUnit("step", metre, 3 / 4, "step")` 可以定义一个长度单位，每步固定为四分之三米。使用 `.of(4)` 构造 4 步，再换算成米应得 3。这个接口适用于乘上固定比例的换算。

    如果用 `Integer(3)` 构造 3 厘米，换成米时，原来的整数类型无法表示 0.03。可显式换用 `inUnit(metre, element: Number)`。当前实现会在运算时检查量纲，量值类型的参数指定保存数字的类型。

## 带走这三样

- 用 `.of(...)` 给数值附上单位。
- 加减要求量纲相同，乘除会组合量纲。
- `inUnit` 保留单位，`valueIn` 取指定单位下的数字。
